# Next JS Full Stack Authentication Project

This project is to showcase my ability to create a full stack project using nextjs and react to authenticate a user.

The project uses the MERN stack with nodemailer to send a user an email to verify their account through a link sent to their signup email address.

## Things I'm happy with
I am happy with how smooth the SPA is and how well it is implemented.

## Things I need to improve
A few unneccessary things like the template home page is still there, I can quickly change it, also the website is bland but the point is for authentication.

## Things I will like to add in the future
A OTP to ensure the user have access to their email, A reset password page and a forgot password page. I would also love to add rate limiting. Lastly a specific password that requires a special password, number and have a minimum and maximum character limit.

Some of these features that I will add in the future, I have already done in other projects that are not currently completed but I will add them into my github in the future.
